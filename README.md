# DABAR

## 비공개 응답 수집과 파일 발송 설정

1. 비공개 Google 스프레드시트를 만들고 `응답` 시트를 생성합니다. 첫 행은 `접수일시`, `성함`, `이메일`로 둡니다.
2. 스프레드시트의 Apps Script에 `다바르_메일발송.gs` 내용을 붙여 넣습니다. Apps Script의 **프로젝트 설정 → 스크립트 속성**에 `SPREADSHEET_ID`와 `ADMIN_TOKEN`을 등록합니다. 관리자 토큰에는 새로 생성한 충분히 긴 무작위 값을 사용하고, 소스 코드나 공개 저장소에는 기록하지 않습니다. `ADMIN_TOKEN`이 없거나 빈 값이면 관리자 발송 요청은 거부됩니다.
3. Apps Script를 웹 앱으로 배포합니다. 실행 사용자는 본인, 접근 권한은 홈페이지 방문자가 요청할 수 있는 범위로 설정합니다.
4. 배포된 웹 앱 URL을 `index.html`의 `SIGNUP_ENDPOINT`에 입력합니다. 별도로 보관 중인 관리자 HTML이 있다면 해당 파일의 `SEND_ENDPOINT`에도 입력합니다.
5. 홈페이지 파일은 공개하고, 관리자 HTML은 관리자만 접근할 수 있는 별도 비공개 위치에 둡니다. 관리자 HTML은 공개 저장소에 포함하지 않습니다. 화면을 숨기는 것만으로 서버의 인증을 대신할 수는 없습니다.

홈페이지에는 응답 목록을 출력하지 않습니다. 응답은 스프레드시트의 `응답` 시트에만 저장되며, 관리자 HTML에서 제목과 내용을 입력하면 해당 주소로 발송됩니다. 첨부 파일은 선택 사항이며, 파일을 고르지 않으면 첨부 없이 발송됩니다. 실제 발송 전에는 테스트 주소 한 개로 먼저 확인하세요.

## 기존 운영 환경 업데이트

GitHub에 소스를 올려도 이미 배포된 Apps Script는 자동으로 변경되지 않습니다. 운영자는 스크립트 속성을 설정하고, 변경된 서버 코드를 반영하여 웹 앱 배포를 업데이트해야 합니다. 과거에 소스에 기록했던 관리자 토큰을 운영에서 사용했다면 반드시 폐기하고 새 값으로 교체하세요. 현재 파일에서 값을 제거해도 과거 Git 기록이나 다른 사람의 복사본에서는 사라지지 않습니다.

## 공개 저장소 포함 범위

- 홈페이지, 비밀값을 제외한 서버 소스, 로고 파일 및 로고 생성 스크립트를 관리합니다.
- 글꼴을 배포할 때는 `assets/brand/fonts/OFL.txt`를 함께 유지합니다.
- 내부 기획 문서, 생성된 보고서, 관리자 HTML, 비밀 설정과 운영 데이터는 `.gitignore`로 제외합니다.
