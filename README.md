# DABAR

## 비공개 응답 수집과 파일 발송 설정

1. 비공개 Google 스프레드시트를 만들고 `응답` 시트를 생성합니다. 첫 행은 `접수일시`, `성함`, `이메일`로 둡니다.
2. 스프레드시트의 Apps Script에 `다바르_메일발송.gs` 내용을 붙여 넣고 `SPREADSHEET_ID`와 `ADMIN_TOKEN`을 변경합니다.
3. Apps Script를 웹 앱으로 배포합니다. 실행 사용자는 본인, 접근 권한은 홈페이지 방문자가 요청할 수 있는 범위로 설정합니다.
4. 배포된 웹 앱 URL을 `index.html`의 `SIGNUP_ENDPOINT`와 `다바르_관리자_메일발송.html`의 `SEND_ENDPOINT`에 각각 입력합니다.
5. 홈페이지 파일은 공개하고, `다바르_관리자_메일발송.html`은 관리자만 접근할 수 있는 별도 비공개 위치에 둡니다.

홈페이지에는 응답 목록을 출력하지 않습니다. 응답은 스프레드시트의 `응답` 시트에만 저장되며, 관리자 HTML에서 파일을 선택하면 해당 주소로 첨부 발송됩니다. 실제 발송 전에는 테스트 주소 한 개로 먼저 확인하세요.
